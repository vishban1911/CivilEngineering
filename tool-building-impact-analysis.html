Building Material Stiffness
Guideline (Burland & Wroth 1975): E/G = 2.6 for an isotropic elastic material. Real masonry/brickwork is more flexible in shear once cracked, so higher values are often adopted: E/G ≈ 12.5 is a common representative value for masonry, up to ≈ 18 for heavily fissured brickwork.
